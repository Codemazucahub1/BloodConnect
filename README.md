# 🩸 BloodConnect

**API REST para gerenciamento integrado de doadores, hemocentros, estoques de sangue e solicitações hospitalares.**

O BloodConnect é um projeto acadêmico desenvolvido com o objetivo de facilitar o gerenciamento de informações relacionadas à doação de sangue, conectando doadores, hemocentros e hospitais por meio de uma API REST.

## 🚀 Sobre o projeto

A aplicação permite organizar informações de doadores, consultar hemocentros e seus estoques de sangue, além de registrar solicitações hospitalares.

O projeto foi desenvolvido para praticar conceitos de desenvolvimento backend, criação de APIs REST, integração com banco de dados relacional e operações CRUD.

## 🛠️ Tecnologias utilizadas

- **Node.js** — execução do JavaScript no backend.
- **Express** — criação e gerenciamento das rotas da API.
- **MySQL** — armazenamento e gerenciamento dos dados.
- **Insomnia** — realização de requisições HTTP e testes dos endpoints.

## 📌 Funcionalidades

- Cadastro e consulta de doadores.
- Atualização e exclusão de registros de doadores.
- Consulta de hemocentros cadastrados.
- Consulta dos estoques de sangue por hemocentro.
- Consulta de hospitais cadastrados.
- Consulta de solicitações hospitalares.
- Integração com banco de dados MySQL por meio de consultas SQL e chaves estrangeiras.
